# Reflection

This project helped me a lot in gaining the confidence to build a real-world live application that is useful in today’s AI-driven environment. The application helps users optimise their AI tool plans based on their actual workload and task requirements.

For this project, I used ChatGPT and Claude AI as development assistants. I did not use any one-shot AI website builder or fully automated code generation platform where the complete application is generated in a short time. I worked on building and understanding the application step by step during development.

## ChatGPT Usage

During development, I used ChatGPT for:
- generating logo ideas
- generating application title ideas
- validating whether my existing layout structure from previous projects was suitable for this project
- debugging errors that I found difficult to solve
- understanding TypeScript and Next.js issues

ChatGPT helped me save time by helping identify where errors might be occurring instead of manually searching through the entire project.

## Claude AI Usage

I used Claude AI mainly for:
- improving Tailwind CSS styling
- refining UI layouts
- improving animations, spacing, borders, colours, width, and height adjustments
- improving overall SaaS UI appearance
- understanding Anthropic API integration
- generating and refining AI summary logic
- optimising certain code structures

Claude AI also helped gather AI tool pricing and plan information such as:
- ChatGPT Plus
- Claude plans
- team plans
- other AI subscription pricing

This reduced the amount of manual research needed for each individual tool and pricing model.

## Challenges Faced

Some of the major challenges during development included:
- TypeScript typing issues
- API route debugging
- build errors
- dynamic routing
- AI summary integration
- deployment issues on Vercel
- folder naming and routing issues

## What I Learned

This project helped me better understand:
- Next.js App Router architecture
- API route handling
- Tailwind CSS
- AI integration workflows
- SaaS application structure
- optimisation and recommendation systems
- deployment and debugging workflows

If given more time, I would improve:
